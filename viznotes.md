
HTML viz illustrating token depth is composed like this. Tokens are assembled sequentially as for tokengraph_to_html,including color highlighting, but blocked by their verbal unit. Each block should be visually indented a number of units equal to the depth of the verbal expression, using CSS only for visual layout. Example: in *taurum cum quo Pasiphae concubuit ex Creta insula Mycenis uiuum adduxit*, there are two verbal expressions anchored to *concubuit* and *adduxit*. The expression with *adduxit* is independent with depth 0, *concubuit* is dependent after the relative pronoun with depth 1. The first token *taurum* belongs to *adduxit*, so it is added to a block with level-0 indentation. The next four tokens *cum quo Pasiphae concubuit* all belong to the same level-1 verbal expression, so they will all be added to a block with level-1 indentation. The remaining tokens *ex Creta insula Mycenis uiuum adduxit* all belong to the level-0 block. The result will be three blocks, at levels 0, 1 and 0 respectively.
